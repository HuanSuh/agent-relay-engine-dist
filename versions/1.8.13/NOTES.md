# agent-relay-engine 1.8.13 릴리스 노트

바뀐 범위: 1.8.12 → 1.8.13

### claude

- **`claude.addDirs` 는 정규형 경로만 받는다 — 엔진 칸과 세션 칸(`resolveSession` 의 `claude.addDirs`) 모두.** `..`·`.` 조각, 끝 `/`, 겹친 `//` 가 있는 경로(`path.normalize(d) !== d`)와 루트 `/` 는 설정 오류다(엔진 칸은 엔진 생성 때, 세션 칸은 그 턴이 CLI 를 띄우지 않고 `error(config, '세션 설정 실패')`, 글은 `detail.cause`; 오류 글에는 경로 원문 대신 `addDirs[i]` 순번만). 정규화하면 같은 경로가 중복 검사를 빠져나가고 `/` 는 파일 시스템 전체를 열기 때문이다. 문자열 정규형만 보며 파일 시스템·심볼릭 링크는 읽지 않는다 — 링크 해석은 호스트 몫이다.
- 영향: 끝 `/`(`/srv/docs/`)·`..`·`.`·`//` 를 쓰던 엔진 설정과 `resolveSession` 훅이 설정 오류가 된다. 루트 `/` 를 넣던 구성도 마찬가지다.
- 소비자 할 일: `path.normalize` 결과로, 끝 `/` 없이 준다(`/srv/docs/` → `/srv/docs`). 루트는 넣지 않고 필요한 폴더만 고른다.
